Executable backlog · start to release

A task only ends when the proof withstands an attempt to break it.

One persistent Linux host per user, Distill as the only harness, Elysia/Eden API and clients with shared services. Network, Docker, Distill, storage, and integration failures are part of the contract from the foundation. Tasks begin at To do; blocked tasks record missing prerequisites. This file is a plan, not a progress report.

How to use this backlog
Start

Open the task only after the IDs in “Depends on” have accepted evidence. “Start” describes the state that must exist.

Finish

“Delivery” is the requested behavior. “Proof” injects real failures when the operation can be ambiguous; attach result, environment, version, and artifact.

Fail

If any condition in “Fail if” occurs, the task returns to execution. Timeout does not prove rollback, and green CI does not replace real recovery.

Scope: Bot computer/browser for human intervention included. Generic browser/preview, Token Saver, and previous harnesses excluded. An unknown failure must end in an explicit and recoverable state, without automatic repetition of uncertain effect. No task authorizes deleting production data.

Depends on: RC-001 · Status: Blocked — Linux CLI login and session setup succeeded, but the stdio prompt timed out before file verification.
Blocker

Checked 2026-09-24: official Distill v2.0.14 Linux x86_64 binary's published SHA-256 matched and distill --version and distill --help succeeded inside a network-isolated Debian 12 amd64 guest (image digest sha256:3783cc01769c7b2b1b83a5c5ad96c815348e28ed7da68e2e3687004faa906251). The separate official ARM64 binary still exits with Illegal instruction (132) in the cached ARM64 guest. CLI startup/help, cached-token authentication, and session creation succeeded in the Linux guest. A real `session/prompt` request for file creation then timed out after six minutes; the workspace file was absent when checked. The client did not retain the session ID or a durable usage receipt, so whether the provider processed or billed the request is unknown. Do not retry until that effect is reconciled. Interruption, process restart, and state/file reconciliation are still unproven; no credential values were read or recorded. See checkpoint evidence.
