Decisões recomendadas

TemaRecomendaçãoValidação
GUIBackend e GUI desktop Linux no container; frontend web desenha a interface das referênciasMesmas funções operáveis na GUI desktop e via API do backend
Controles remotosWeb/iOS consultam o mesmo backend com apresentação própriaWorkspaces, Bots, threads, comandos e reconexão em desktop/iPhone reais
DistribuiçãoMesma imagem aberta para instalação própria e hospedagem pagaInstalação autogerenciada e exportação/restauração dos dados
Isolamento hospedadoContainer e volume por usuário; uma VPS por usuário no betaRestauração em novo container, custo mensal e acesso cruzado negado
RAM4 GB no piloto; 8 GB se concorrência real falharPico RSS, swap, OOM e latência de API/stream
Push de tudoInbox persistida no backend para todos os eventos relevantes; push padrão para ação/falha/conclusãoTeste de volume, preferência e privacidade
Downtime da tarefaMarcar skipped e oferecer Run NowSem repetição de efeito externo
iOSApp nativo e PWA como clientes do backendMesmos objetos e ações, APNs e Web Push separados
Dados locaisImportação opt-in ensaiadaChecksum, rollback e reautorização de segredos
Autoridade após migraçãoFence de escrita local por workspace; retorno reconciliadoEnsaio com alterações no container após cutover
Estado de UIEstado de negócio no container; seleção e layout por dispositivoDois dispositivos veem os mesmos dados sem trocar o foco um do outro
ProvedoresValidar termos, autenticação, quota e limite de gasto por providerRun Linux dentro do teto e falha clara ao exceder

Incertezas materiais

  • Como disponibilizar a janela desktop Linux do container para quem a usar, separadamente da interface web por API.
  • Como portar a GUI AppKit/SwiftUI para Linux e expor pelo backend os recursos de terminal, browser, agentes e Bots.
  • Qual contrato de API/eventos permite ao web e iOS mostrar listas, threads, runs e ações com reconexão correta.
  • Licença de código aberto e nome/marca da distribuição ainda precisam de definição.
  • Como entregar push ao app iOS a partir de instalações próprias sem depender da conta hospedada.
  • Compatibilidade dos três providers e Token Saver em Linux, especialmente com 4 GB.
  • Inventário completo dos dados locais e integrações exclusivas do Mac que usuários usam hoje.
  • Preço por VPS, armazenamento, backups e egress versus receita/limites desejados.
  • Definição final do usuário para frequência de push de sucessos rotineiros e eventos de segurança.
