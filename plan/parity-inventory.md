## Explicit exclusions

- **Token Saver:** the macOS app documents this feature, but it is excluded from the RemoteCode plan scope; it is not a new-product requirement or a dependency for the planned Distill integration.
- **Generic browser and preview surfaces:** the current app includes browser and preview tabs, but the plan explicitly excludes generic browser/preview parity. The Bot's dedicated computer/browser session for human login remains in scope through RC-023–RC-025, RC-041–RC-044, RC-052, and RC-057.
- **Previous/parallel agent harnesses:** the current app supports several agent providers and local/worktree modes, but RemoteCode's plan specifies the main Distill project as the only harness. No legacy harness or RemoteCode fork is required; see RC-002, RC-022, RC-034, and RC-040.
- **WatchOS and Live Activities:** the current app README describes a watch companion and Live Activities, but the new product plan targets web/desktop, iOS, and Android and defines no watchOS client or proof. These surfaces are therefore not included in planned parity.
